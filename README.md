# Learning JFrog Artifactory

This repository contains some notes and examples I've put together while learning JFrog Artifactory.

The aim is to help other QA engineers get familiar with Artifactory, understand what it's used for, and see how it fits into software testing and development.

No previous experience with JFrog is needed.

## What's Covered?

- What JFrog Artifactory is and why it's used.
- Understanding artifacts and repositories.
- Setting up Artifactory locally using Docker.
- Navigating the Artifactory interface.
- Creating repositories and managing artifacts.
- How Artifactory relates to QA and CI/CD.
